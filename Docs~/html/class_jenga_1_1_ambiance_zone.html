Detailed Description

Simple Ambiance Zone on Collider.

Moves AudioSource to closest point to AudioListener inside collider, and blends sound to stereo if AudioListener is far away, making it sound as if given AudioPlayer plays inside some zone. You may also want to setup some reverb on sound separately.
